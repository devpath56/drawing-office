# 7. The context plugin is a Proposal the machines call

Date: 2026-09-15

## Status

Proposed

## Context

The operator, 2026-09-09: the plugin layer is the product — a harness-shaped factory that plugs into
a target company's own workflows, reusing DeepSeek's open-source packages. The same evening ruled the
layer as two things: governance and RBAC wrap every container as a boundary, while context and
inference are containers the machines call. What a session is handed at the moment it opens is the
context plugin; today the fan-out packet does that job inside operator control, and no package has
been searched for it.

## Decision

The context plugin is drawn as one Proposal container with technology "DeepSeek OSS, unsearched", so
the box says both that it is proposed and that its candidates have not been through the procurement
door. Every machine's edge to it is described as the ask a session makes at open.

## Consequences

A reader sees that the packet exists and the plugin does not. The tag is retired when a candidate is
ruled through the OSS doors and the packet is re-homed, with its own record.
